# 奶娃博物馆 (Naiwa Museum)

一个基于原生前端技术（HTML5 / CSS3 / ES6）构建的**奶娃 / 奶龙名画画廊网站**。以经典名画与奶娃、奶龙拟态形象为主题，具备开屏入场动效、滚轮驱动视差揭示过渡、左侧垂直大弧度标签轮播系统以及全部作品网格总览。

---

## 🌟 核心特性

1. **开屏入场动效 (Splash Intro)**
   - 深色开屏背景，网站主标题「奶娃博物馆」字形逐字浮现入场；
   - 居中配备几何徽章与线框角标装饰；
   - 底部带有鼠标滚动指引，向下滚动即可进入画廊。

2. **滚轮驱动视差揭示过渡 (Scroll-Driven Parallax Portal)**
   - 用户向下滚动鼠标滚轮（或触控上滑）时，画廊页面从视口下方平滑向上滑入并覆盖开屏；
   - 开屏背景与画廊之间形成差速视差滚动效果；
   - 右上角提供返回按钮，点击可平滑退回开屏首页。

3. **左侧垂直大弧度标签轮播 (`js/arc-carousel.js`)**
   - **靠左布局**：固定在屏幕左侧，布局整齐直观；
   - **文字平直易读**：标签始终正向水平排列，无倾斜干扰；
   - **选中高亮**：当前选中项放大加粗，并带有发光效果与指示条；
   - **点击直达**：点击任意标签直接平滑过渡至目标作品；
   - **循环滚动**：支持向上或向下无限循环滑动。

4. **收录 63 幅 WebP 本地图片 (`assets/` 目录)**
   - 涵盖文艺复兴、浪漫主义、印象派、巴洛克及三国系列等多种风格的奶娃 / 奶龙画作；
   - 图片全部采用 **WebP** 格式，体积小、加载快；
   - 内置静默预加载机制，切换作品更流畅；
   - 支持图片加载失败自动降级为主题色占位，避免白屏。

5. **全部作品网格总览 (Grid Overview)**
   - 点击右上角「九宫格」按钮，即可展开全部 63 幅作品的响应式网格列表；
   - 支持桌面端多列与移动端自适应排版，展示缩略图、编号、标题与副标题；
   - 点击任意作品可直接跳转展示；支持按 `Esc` 键或右上角关闭按钮返回。

6. **背景音乐与开关控制 (Background Music)**
   - 接入循环背景音乐《人鱼的眼泪》（DJ 降调版，`assets/人鱼的眼泪dj降调版.mp3`）；
   - 右下角常驻悬浮按钮，明确显示「音乐：关 / 开」并带有均衡器动画，点击即可随时开启或静音。

## 🖼️ 如何新增图片

1. **添加图片**：将新图片（推荐 `.webp` 格式）放入 `assets/` 目录；
2. **配置数据**：在 `js/data.js` 的 `GALLERY_ITEMS` 数组中添加对应数据项：
   ```javascript
   {
     id: 64,
     title: "作品名称",
     subtitle: "副标题说明",
     category: "分类 / 作者",
     accentColor: "#HEX颜色值",
     gradient: "linear-gradient(135deg, ...)",
     image: encodeURI("assets/作品名称.webp")
   }
   ```
3. **自动同步**：左侧轮播与网格总览会自动根据数据列表更新，无需修改其他代码。

## 🚀 运行方式

本项目使用纯原生前端开发，无需安装 Node.js 或 npm 依赖：

1. **直接打开**：在文件管理器中双击 [`index.html`](index.html)，即可用现代浏览器直接打开体验；
2. **本地服务（推荐）**：如果浏览器对本地 `file://` 协议有限制，可在项目根目录下运行简易静态服务器：
   ```bash
   python -m http.server 8000
   ```
   然后在浏览器中访问 `http://localhost:8000` 即可。
