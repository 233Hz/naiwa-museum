# CHROMALUX - 纯粹全屏沉浸画廊 & 开屏矩形扩散揭示

一个基于原生前端技术（HTML5 / CSS3 / ES6）构建的**顶级艺术画廊网站**。具备动感十足的开屏入场动效、滚轮驱动从屏幕中心向四周扩散放大的矩形视窗揭示过渡，以及左侧垂直大弧度纯标签轮播系统。

---

## 🌟 核心特性清单

1. **开屏首页与逐字跳跃入场动画 (Splash Intro & Staggered Bounce)**
   - 初始纯净深色开屏背景，网站名称 `CHROMALUX` 自动拆解为单字符节点；
   - 运用三维弹簧缓动曲线（`cubic-bezier(0.34, 1.56, 0.64, 1)`）触发**逐字阶梯跳动浮现动画**，配合从模糊到清晰的平滑渐变；
   - 配以呼吸微光的副标题与向下滚动的操作指引。

2. **滚轮驱动中心向四周矩形扩散揭示 (Scroll-Driven Center Rectangular Portal)**
   - 当用户向下滚动鼠标滚轮（或触摸屏向上轻滑）时，屏幕正中央诞生一个矩形视窗；
   - **四向同步扩散**：基于参数化 `clip-path: inset(...)` 算法，矩形从中心点同时向上、下、左、右四个方向同步均匀放大，直至铺满整个 100vw × 100vh 视口；
   - **实时无缝展示实际页面**：在矩形扩散的整个过程中，矩形内部**实时展示画廊真实的高清大图与左侧圆弧标签**，内容与扩散进度保持严格同步，毫无跳变与白屏；
   - **发光边缘跟随**：扩散的矩形四周附带细微霓虹发光边框，强化视窗破壁的立体仪式感；
   - 开屏文字随进度向上浮动虚化淡出，扩散完成后自动平滑移交滚轮控制权。

3. **左侧大弧度纯标签轮播 (`js/arc-carousel.js`)**
   - **紧凑靠左布局**：整体位于屏幕左侧 $60\text{px} \sim 100\text{px}$ 黄金阅读区间；
   - **纯平面正向显示**：所有文字完全水平平直，绝无任何俯仰斜角，清晰易读；
   - **无框高亮设计**：正中选中项字号放大至 1.35rem、900 加粗并附带霓虹文字发光辉光与 32px 荧光指示条；
   - **单次直达过渡**：点击任意标签时，画面直接单次过渡至目标图片，跳过中间项闪烁；
   - **无缝环形循环**：支持无限向上或向下滚动，圆弧两端始终对称饱满。

4. **全部 60 幅本地高清典藏（`assets/` 目录）**
   - 内置静默预加载器（Preloader），首屏自动在后台预取全部大图，确保切换时毫秒级瞬时呈现；
   - 全部为本地素材，无需联网即可展示；个别大图加载失败时卡片自动降级为展项主题色占位，绝不白屏。

5. **全部展品总览网格视图 (All-Works Grid Overview)**
   - 沉浸式画廊右上角新增「九宫格」按钮，一键展开**全部 60 幅展品**的响应式网格总览；
   - 网格自适应列数（桌面多列 / 移动端单列），每张卡片含缩略图、编号、标题与副标题；
   - 点击任意卡片即可**直达沉浸展厅对应展品**；按 `Esc` 或右上角关闭按钮返回。

6. **背景音乐与全局开关 (Background Music Toggle)**
   - 已接入 `assets/人鱼的眼泪dj降调版.mp3` 作为循环背景音乐；
   - 右下角常驻悬浮按钮，清晰标注「音乐：关 / 开」并附带播放均衡器动效，**随时一键开启或关闭**；
   - 因浏览器策略禁止自动播放，音乐默认关闭，需用户首次点击按钮后开始播放。

## 🖼️ 如何新增 / 批量加入图片

1. 将图片放入 `assets/` 目录（建议中文或英文文件名均可，代码已对路径做 `encodeURI` 处理）；
2. 在 `js/data.js` 的 `GALLERY_ITEMS` 数组中追加一项，至少包含 `id`（唯一序号）、`title`、`subtitle`、`category`、`accentColor`、`gradient`、`image` 字段；
3. 网格总览与左侧弧标轮播会**自动包含**新作品，无需改动其它代码。

> 本次更新已将 `assets/` 下新增的 **44 幅**图片（如十字军东征、夜巡、星空、自由引导奶龙、奶破龙系列、奶龙系列等）批量加入，连同原有 16 幅，全馆共 **60 幅**展品。
